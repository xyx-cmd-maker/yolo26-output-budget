# Data license for the corrected TP-prefix records

The JSON files in `records/` are derived numerical records computed from
VisDrone2019-DET validation annotations and YOLO26n predictions. They contain
image file names, object counts, prediction counts, and cumulative true-positive
counts. They do **not** contain images, raw annotation boxes, or personal data.
